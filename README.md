# pos-reminder

Утреннее напоминание в Telegram: раз в день присылает текущий шаг по учёбе.
Личных данных здесь нет — только шаг и ссылка на урок. Основная система (vault) живёт локально на ноутбуке.

- `step.md` — что делать сегодня
- `notify.py` — собирает сообщение и отправляет
- `.github/workflows/morning.yml` — расписание: 07:00 UTC = 10:00 GMT+3
- Секреты репозитория: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`
